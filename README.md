# hospital-data-management-sql
A  SQL project using a hospital database. This project covers essential SQL operations such as table creation, data insertion, joins, aggregation, and filtering—ideal for learning how to manage and query healthcare-related datasets.
This project features a structured SQL assignment based on a simplified hospital database. It provides hands-on experience with foundational SQL queries and database design concepts.

## Key Features

- Simulates a hospital management system with multiple tables
- Covers SQL operations: `CREATE`, `INSERT`, `SELECT`, `JOIN`, `GROUP BY`, and more
- Helps develop real-world data querying skills in a healthcare context

## What's Included

- `micro course assignment.sql`: Contains all SQL statements used in the assignment

## Target Audience

Perfect for:
- Students learning SQL
- Beginners practicing with healthcare-related data
- Anyone preparing for SQL interviews
